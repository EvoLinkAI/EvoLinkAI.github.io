# Evolink Integration Guides

This section will host approved setup guides for open-source partner projects.

Each guide is published after the project maintainer approves the integration wording and public listing.

## Standard Configuration

Most partner guides use Evolink's OpenAI-compatible endpoint:

```env
OPENAI_BASE_URL=https://api.evolink.ai/v1
OPENAI_API_KEY=your_evolink_api_key
```

Project-specific instructions will be added as each partner confirms the final docs.
