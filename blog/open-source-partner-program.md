# EvoLink Open-source Partner Program

EvoLink is building an open-source partner program for projects that add model-provider or OpenAI-compatible API support.

The goal is practical distribution for maintainers and clearer onboarding for developers:

1. A confirmed Partner Card on the Evolink partners page.
2. A setup guide for using the project with Evolink-compatible API access.
3. Optional blog and X announcements when the maintainer approves public promotion.
4. Tracking links so we can measure clicks, signups, and first API calls.

We only publish named partner assets after maintainer confirmation.

Maintainers who have merged Evolink or compatible provider support can reply in the merged PR thread or contact Evolink Partnerships to approve the public listing.
