# EvoLink Open-source Partners

EvoLink works with open-source projects that add Evolink or compatible model-provider support.

This page lists confirmed partners only. Projects are added after maintainers approve the listing, tracking link, and public assets.

## Partner Activation Flow

1. A project merges provider or API support.
2. Evolink confirms the listing with maintainers in the merged PR thread or by email.
3. Maintainers approve the public Partner Card, docs guide, blog post, and optional X announcement.
4. Evolink publishes the approved assets and tracks activation metrics.

## Current Status

The first post-merge partner outreach batch is in progress.

- 5 merged projects have received initial maintainer outreach.
- 5 activation tracking issues are live in the Evolink GitHub Pages repository.
- The next scheduled maintainer follow-up is June 22, 2026 for projects that have not replied.
- Confirmed partner cards will appear here only after maintainer approval.

## Maintainer Approval Checklist

Before a named project appears publicly, Evolink confirms:

1. The maintainer approves the public listing.
2. The project link and one-line description are approved.
3. The logo or visual asset is approved.
4. Any docs, blog, or X announcement is approved separately.
